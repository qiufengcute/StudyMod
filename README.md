**Answer questions, earn rewards, or face lightning!** A fun mod that brings the famous Chinese study guide "Five-Three" into Minecraft. Answer questions from three subjects (Chinese, Math, English), earn valuable rewards, or get struck by lightning for wrong answers!

---

## ✨ Features

### 📚 **Core Gameplay**
- **Craft the "WuSan Exercise"**: Create the classic study guide using basic materials
- **Right-click to start quiz**: Hold the book and right-click to open the quiz interface
- **Eight fixed questions**: 1 Chinese + 4 Math + 3 English questions

### 🎯 **Quiz Subjects**
- **Chinese** × 1 question: Basic language knowledge
- **Math** × 4 questions: Calculation and logic problems
- **English** × 3 questions: Vocabulary and grammar


### ⚡ **Exciting Reward System**
- **Correct answer reward**: Get **1 Netherite Ingot** for each correct answer!
- **Ultimate rare reward**: **1% chance** to get the **"WuSan Sword"** - a powerful weapon that can kill almost any mob instantly!
- **Wrong answer punishment**: Get struck by **lightning** for each wrong answer!
- **Instant results**: See rewards or lightning immediately after each question

### ⚔️ **"WuSan Sword" - The Ultimate Weapon**
- **Extreme Damage**: Can almost one-shot all original creatures (including Bosses!)
- **Rare drop**: Only 1% chance to obtain from correct answers
- **Unique ability**: Special visual effects when attacking
- **Can Repair**: Use "Wusan Exercise" to repair

## 🔧 **Installation** 
### **Requirements**
- Minecraft Version: 1.21.8-1.21.10
- Mod Loader: Fabric
- **Required**: [Fabric API](https://modrinth.com/mod/fabric-api)
### **Installation Steps**
1. Make sure you have the correct mod loader installed
2. Download the mod .jar file
3. Put it in `.minecraft/mods` folder
4. Launch the game
### **Important Notes**
- **Single Player**: Install and play directly
- **Multiplayer**: Both the server AND all connecting players must have this mod installed.
- **Environment Setting**: This mod is marked as "Optional on both Client and Server"

## ⚠️ **Warnings & Tips**
1. **Lightning Danger**: Wrong answers cause lightning that may start fires
2. **Rare Sword**: The WuSan Sword is extremely powerful(Damage: 99,999) - use wisely!
3. **Single Use**: Each Exercise Book is consumed after one quiz session.
4. **Fixed Questions**: 8 fixed questions in random order

---

## ⚙️ **Configuration**
- **`/gamerule summonLightningOnWrong <true/false>`**
  - Default: `true`
  - Controls whether wrong answers trigger lightning strikes.
  - Set to `false` for a punishment-free learning experience!

## ❓ **FAQ** 
**Q: Are the questions random?**  
**A:** 8 fixed questions in random order each time. 

**Q: Can I modify the questions?**  
**A:** Currently requires modifying mod files. 

**Q: Can the WuSan Sword break?**  
**A:** Yes, it's breakable. But you can use "Wusan Exercise" to repair.

**Q: Will lightning kill me?**  
**A:** It causes damage but won't kill instantly (unless you're already low health). 

**Q: Can I get multiple WuSan Swords?**  
**A:** Yes, but each has only 1% drop chance per correct answer.
